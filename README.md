Descripción de la evaluación:
Este repositorio contiene los entregables correspondientes a la Evaluación Práctica 2. El proyecto consiste en el desarrollo de un modelo estadístico predictivo (Regresión Lineal) para estimar el Ingreso Mensual Recurrente (MRR) del próximo trimestre para los clientes B2B de la empresa SaaSFlow. El desarrollo abarca desde el diagnóstico inicial (EDA), limpieza y preprocesamiento (tratamiento de nulos, escalado, codificación categórica e ingeniería de características) asegurando que no exista fuga de datos (data leakage), hasta el entrenamiento del modelo y la evaluación mediante las métricas R² y MAE interpretadas bajo un contexto de negocio y retención de clientes.

Entregables (Directorio E2-Regresión):
- E2.ipynb: Script/Notebook ejecutable con el pipeline completo de datos y modelado.
- Presentacion_E2_MRR.pptx: Presentación ejecutiva orientada a la toma de decisiones.
