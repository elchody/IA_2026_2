## Descripción

Este proyecto evalúa la calidad del dataset de rendimiento académico, documenta y trata valores faltantes, duplicados, inconsistencias y atípicos, desarrolla un análisis exploratorio de datos (EDA), responde las preguntas de investigación solicitadas y genera una versión transformada mediante un `Pipeline` de scikit-learn.
